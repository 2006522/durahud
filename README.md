# 耐久显示(DuraHUD)

把身上装备和手上工具的**剩余耐久**直接摆在屏幕上，用的是游戏原版的物品图标，
一眼就能看出哪件快坏了。

位置随便拖，拖完记着，下次进游戏还在原地。

纯客户端模组，**单人存档和联机都能用**，服务端不用装。

适用于 Minecraft **26.4-snapshot-5** / Fabric。

## 下载

到 [Releases](https://github.com/2006522/durahud/releases) 页面下载最新的
`DuraHUD-<版本号>.jar`。

## 安装

1. 先装好 **Fabric Loader**（0.19.5 或更新）和 **Fabric API**
2. 把 `DuraHUD-<版本号>.jar` 丢进 `.minecraft/mods/`
3. 启动游戏

进游戏就能看到，不用做任何设置。

## 用法

### 设置与拖动位置

两种方式都能打开设置界面：

1. **打开背包，点面板左侧的 `HUD` 按钮**（生存背包和创造物品栏都有，不挡格子）
2. **按 F10**（可在「选项 → 控制 → 按键绑定 → 耐久显示」里改键）

设置界面里可以：

- **选数字显示方式**
  - `百分比` → `62%`
  - `数字（当前/总共）` → `156/250`

  当前生效的那个前面有 `▶`，点一下立刻生效。下方「预览」一行能马上看到改成什么样。
- 点 **「编辑 HUD 位置」** 去拖动 HUD 本身：
  - 用鼠标把 HUD 拖到想放的地方
  - 方向键一格一格微调
  - 按 **ESC** 回到设置界面
- 点 **「恢复默认位置」**：HUD 和背包按钮一起回到默认位置（两边都拖乱了时用）
- 点 **「完成」** 关掉，从背包进来的会回背包，按 F10 进来的直接回游戏

拖动时界面不会变暗，能直接看到游戏画面，方便对着实际界面调位置。

**位置会记住**，重进游戏还在原地。如果换了窗口大小或界面缩放，位置会自动收回可视范围
（不会跑到屏幕外"消失"）。

**背包里那个 `HUD` 按钮自己也能拖**：按住不放拖到别处松手就停在那儿，位置会记住；
轻点（没移动）才是打开设置。拖不出屏幕边缘。

### 显示什么

按顺序列出：

1. 头盔
2. 胸甲
3. 护腿
4. 靴子
5. 主手
6. 副手

**只显示带耐久的物品**。空手、火把、方块这些没有耐久概念的东西不会占位置，
所以栏目的行数会随你换装备而变化。

每一行长这样：

```
[物品图标]  62%
   ▬▬▬▬▬▬▬▬▬
```

- 图标就是背包里那个图标，游戏原版画的，材质包改了它也跟着改
- 下面的细条是剩余比例
- 右边是数字，可以改成百分比 / 剩余值 / 剩余/上限

颜色分三档，跟原版耐久条一个思路：

| 剩余 | 颜色 |
| --- | --- |
| 50% 以上 | 绿 |
| 25% ~ 50% | 黄 |
| 25% 以下 | 红 |

## 配置

配置文件在 `.minecraft/config/durahud.properties`，第一次启动会自动生成。

> 位置和显示方式用**设置界面**改最方便（背包里的 `HUD` 按钮 / F10），下面这些值是它写进去的。
> 想用配置文件直接改也行，改完重启游戏生效；手改 `text` 还能选到界面上没有的 `remain` / `none`。

```properties
# 总开关
enable=true

# HUD 位置（打开编辑界面拖完会自动写回这里）
x=6
y=6

# 显示哪几类
show_armor=true
show_held=true

# 数字怎么显示：percent / remain / both / none
text=percent

# 是否画半透明底板，关掉就只剩图标和条
background=true

# 背包里 HUD 按钮的位置（GUI 坐标，拖动按钮后自动写回）
button_x=0
button_y=0
# 下面两项只在第一次落位 / 「恢复默认位置」时用到：
# 按钮第一次出现时摆在「面板左上角 + 偏移」处，之后就固定在上面那两个坐标
button_dx=-30
button_dy=4
```

`text` 四种取值：

| 值 | 显示成 |
| --- | --- |
| `percent` | `62%` |
| `remain` | `156` |
| `both` | `156/250` |
| `none` | 只有图标和条，不显示数字 |

改完文件重启游戏生效。位置不用手改，用编辑界面拖就行。

## 环境要求

- Minecraft **26.4-snapshot-5**
- Fabric Loader **0.19.5** 或更新
- Fabric API
- Java **25**

## 已知限制

- **只统计耐久，不显示附魔、命名、数量**。一堆同样的工具会各占一行，不合并。
- **盔甲架、马铠之类不显示**。只看玩家自己的六个槽位。
- **F1 隐藏界面时会跟着一起藏起来**，跟原版 HUD 行为一致。
- 装光影时 HUD 由游戏自己画，不受影响。
- 界面缩放（GUI Scale）变了以后位置是按比例存的绝对值，可能需要重新拖一下。
